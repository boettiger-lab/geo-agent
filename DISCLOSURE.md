Portions of the code, tests and documentation in this repository, in particular much of the `app/` modules, the `test/` suite and the guide in `docs/`, were drafted with the aid of large language model coding tools: Anthropic Claude models (Claude Sonnet 4.6, Claude Opus 4.6, Claude Opus 4.8, and Claude Opus 5.5, model ID `claude-opus-5-5`), accessed through the Claude Code command-line tool, beginning February 2026.

The authors directed this work and reviewed, tested, and validated the results, including the automated test suite run on every pull request, live previews of visible changes, and checks against deployed apps and the LLM proxy logs. The authors take full responsibility for the code, tests and documentation, and any errors they contain.
